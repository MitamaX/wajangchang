# 검색은 Grep·Glob 도구로

코드와 파일 검색에 셸의 `grep -rn`이나 `find`를 쓰지 않는다. 내용 검색은 Grep 도구, 파일명 검색은 Glob 도구를 쓴다.

**Why:** 셸로 저장소 전체를 훑으면 `bin/`, `obj/`, `artifacts/`까지 들어간다. 실제로 `grep -rn` 한 번이 120초 제한을 넘겨 백그라운드로 밀렸고, 같은 질의를 Grep 도구로 하면 즉시 끝났다. 도구 쪽이 무시 규칙을 이미 적용한다.

**How to apply:** 경로를 아는 단일 파일을 열어 보는 것만 셸로 한다. 셸 검색이 꼭 필요하면 대상 디렉터리 하나로 좁히고 빌드 산출물 경로를 제외한다.
