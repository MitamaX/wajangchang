# 주석 없는 클린 코드

개발 중 주석을 달지 않는다. 대신 주석이 필요 없을 수준의 코드 구조화와 변수/함수명을 사용한다 (clean code 전략).

**Why:** 주석 대신 코드 자체가 의도를 드러내야 한다. 주석은 코드와 어긋나기 쉽고, 이름과 구조로 설명 가능한 것을 중복 설명한다.

**How to apply:** 새 코드를 작성하거나 수정할 때 설명 주석(인라인, 블록, docstring 성격의 요약 주석)을 추가하지 않는다. 대신 함수를 의미 단위로 쪼개고, 의도가 드러나는 변수/함수명을 쓰고, 매직 넘버는 이름 있는 상수로 뺀다. 기존 파일의 주석은 임의로 지우지 않는다.
