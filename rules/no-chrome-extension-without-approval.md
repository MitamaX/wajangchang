# 승인 없이 Chrome 확장 사용 금지

사용자의 승인 없이는 Chrome 확장(브라우저 자동화)을 쓰지 않는다.

**Why:** 브라우저 자동화는 사용자의 실제 브라우저 세션을 건드린다. 탭·로그인 상태·열려 있는 작업에 영향을 주므로 사용 시점은 사용자가 정한다.

**How to apply:** 결과 확인이 필요하면 서버만 띄우고 사용자에게 직접 확인하도록 넘긴다. 브라우저 자동화가 실제로 필요하다고 판단되면 먼저 사용자에게 사용해도 되는지 묻고, 명시적 승인을 받은 뒤에만 `mcp__claude-in-chrome__*` 도구를 호출한다. 승인은 그때 그 작업에 한정되며 다음 작업으로 확장되지 않는다. [passive-scope-active-execution](passive-scope-active-execution.md)와 같은 방향 — 범위 결정권은 사용자에게 있다.
